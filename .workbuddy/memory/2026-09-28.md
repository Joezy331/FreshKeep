# 2026-09-28

## KeepFresh 作品集原型 · 底部导览交互化 + 资产自包含

用户反馈预览面板里手机底部 Tab 图标是破图（原用 `<img src="../assets/tabbar/*.png">`，经本地预览代理只服务单 HTML，外部 PNG 加载失败）。本轮优化 `preview/keepfresh-portfolio.html`：

- **底部导览小图案改为内联 SVG**：新增 `<svg>` sprite（`<symbol>` ic-home/fridge/recipe/profile/camera/pen/album/leaf/empty，共 9 个），所有图标用 `<use href="#ic-*" currentColor>`。颜色靠 `.p-tab .t` 的 `color` 自动切换（非激活 ink300 / 激活 brand 绿），按压缩放清晰。
- **Tab 变成真交互**：每个手机底部 4 个 Tab（首页/冰箱/食谱/我的）点击切换该手机屏幕。实现：
  - `data-tab` 标注；移除原 `data-goto`（避免与切屏冲突）。
  - 每台手机初始化时缓存 `_home`（原 `.p-body` innerHTML）+ 默认 Tab + 标题；点击切屏注入 `SCREENS` 模板（home/fridge/recipe/profile 四套 `.p-body` 模板），默认 Tab 则还原 `_home` 并恢复标题。
  - 每次切屏后重新 `bindPhone(phone)` 绑定内部交互（拍照扫描 / 冰箱筛选 / 临期弹窗 / 食谱换一换），保证还原后仍然可用。
  - `data-goto` 全局处理改为**事件委托**（兼容动态注入的按钮，如模板里「去拍照」跳 sec-02）。
- **顺手把其余外部图也内联**：封面 leaf-deco、首页 4 个 tile 图标、空状态 empty-fridge 全部改为 SVG → 全页 0 处 `assets/` 引用，本地预览与 GitHub Pages 都不再有破图。
- 校验：node --check 通过；div 685/685、svg 23/23 平衡；16 个 data-tab。

**结论**：作品集原型现在是完全自包含、真实可交互的手机原型（Tab 切屏 + 扫描 + 筛选 + 弹窗 + 食谱切换 + 跳转），可直接浏览器打开或部署。安全红线仍守住（未触碰百度 Key）。
