## 修复用户实测反馈的两个问题

1. **CSS 报错（home.wxml 77–79 行 `css-semicolongexpected`）**
   - 根因：WXML 内联 `style="width: {{x}}%"` 缺少结尾分号，开发者工具会按 CSS 校验。
   - 修复：home.wxml 状态条 3 处、recipe-card.wxml、recipe-detail.wxml 进度条，全部补 `%;`。
   - 规则：**WXML 内联 style 一律写完整声明 + 结尾分号**。

2. **拍照功能用不了**
   - 根因：`wx.chooseMedia` 必须由用户点击手势触发；之前在 `onLoad` 里根据
     `?source=camera/album` 直接自动调起，被拒绝（`can only be invoked by user tap gesture`）。
   - 修复（pages/scan/scan.ts 重写）：
     - onLoad 只延迟 500ms 静默尝试一次，失败不提示（页面上本来就有按钮）；
     - chooseMedia 失败自动降级 `wx.chooseImage`；
     - 权限被拒时弹窗引导 `wx.openSetting`；
     - 新增 **Demo 演示识别** 按钮（跳过拍照直接走完整识别链路），
       演示图用 `demo://fresh-basket` 哨兵值，入库时 image 置空、预览显示占位卡。

- 网关信息（实测）：端点 `https://opencode.ai/zen/v1/chat/completions`，
  模型列表 `https://opencode.ai/zen/v1/models`（公开无需鉴权，当前 70 个模型），
  鉴权 `Authorization: Bearer <Zen API Key>`，OpenAI 兼容。
- 免费模型（撰写时）：nemotron-3-ultra-free / mimo-v2.5-free / ling-3.0-flash-fin-free /
  deepseek-v4-flash-free / muse-spark-1.3-contributor-free / nemotron-3.5-lightning-free / big-pickle。
  视觉能力不确定，需换支持视觉的模型（gpt-5.4-nano / gemini-3.5-flash 付费）。
