### 需求
承接 10-12 的「文字居中」修复，用户接着要「排版都要一样」→ 把方框内文字**字号也统一**（此前是分层的：主框 13 / 菱形 12.5 / 副文案 10.5 / AI 角标 9）。

### 做法（batch_edit，15 个 U()）
统一为 **13px**（与主框一致）：
- 菱形文字：9:24 / 9:49 / 9:82 / 9:120 / 9:193 / 9:216 / 9:241（12.5→13）
- 副文案：9:18 / 9:43 / 9:110 / 9:187（10.5→13）
- AI 角标：9:39 / 9:184（→13），同时把角标框 9:38 / 9:183 加宽到 `{width:280, x:0}` 并 `textAlignHorizontal:"CENTER"`，避免长英文角标（"Vision Recognition · Baidu AI Cloud"）在 13px 下溢出小框。

### 结果 / 注意
- 全图框内文字统一 13px、居中；标题区/图例/诚实说明**不动**（它们不属于「方框内文字」）。
- 分支小标签（是·拍照识别 等，10.5px 的药丸）**保持不动**：其容器仅 33–57px 宽，13px 会溢出，故不统一。
- 副作用（可接受）：副文案 13px 后比其 14.2px 高的父帧略高（约 3px），`potentialIssues` 会报「超出父框」，但父框/外框默认不裁剪，肉眼无裁切（在 ≤4px 容差内）。菱形文字同样 1px 级纵向溢出。
- 预览图：`preview/keepfresh-logic-flow.png`（更新，13px 统一版）。

### 复用经验
- Ardot 改字号只需 `U(node,{fontSize:13})`；**改字号后要顺带复核文本宽度是否超出其小容器**（角标/副文案框通常很窄），必要时同步加宽容器。

## 逻辑流程图：三分支溢出 + 两菱形文字再次居中（同文件 735540142556778）

### 需求（用户截图反馈）
1. 三分支行「正常/临期/已过期」间距过宽 → 画布放不下（左右被裁）。
2. 两个菱形文字仍不居中：9:143「用户是否处理？」、9:168「是否从库存移除？」（Round 1 漏改）。

### 根因
- 三分支行 `9:121` 原 `gap:56`，行宽 = 5×280 + 4×56 = 1624px，超过 1440 画布 → 左右各裁约 92px。
- `html_to_ardot` 导入单行文本时用「中心点当左边缘」(x 被设为框中心值)，且这两枚菱形文字节点在早前 `batch_read` 时被压缩漏读，故 Round 1 未覆盖。

### 做法（batch_edit，20 个 U()）
- 间距收窄：`9:121/9:144/9:169` 的 `gap:56→32`；行宽 = 5×280 + 4×32 = **1528**。
- 画布加宽：`9:2` 1440→**1640**（留左右各 56px 对称边距）；`9:121` `x:-148→-100`（绝对左缘=156-100=56，右缘=56+1528=1584，画布 1640 → 右距 56，对称）。
- 内容帧整体右移：`9:9/9:3/9:5/9:7` `x:56→156`。
- 两列内框 `9:130/9:158` 616→**592**（=2×280+32）；其内子节点重定位：`9:131→274 / 9:133→156 / 9:138→290 / 9:140→186`；`9:159→268 / 9:161→156 / 9:163→290 / 9:165→186`。
- 两枚漏改菱形文字：`U("9:143",{width:155.5,x:0,textAlignHorizontal:"CENTER",textAlignVertical:"CENTER",fontSize:13})`、`U("9:168",{width:168,x:0,...,fontSize:13})`。
- 收尾：`9:1` 根框宽 1440→1640，与 `9:2` 对齐，避免编辑器内画布裁切。

### 结果 / 注意
- 三分支行不再溢出画布（对称 56px 边距）；全部菱形文字已居中对齐。
- 仅余 1px 级纵向溢出告警（`9:143/9:168`），在 ≤4px 容差内，父框不裁剪，肉眼无影响。
- 预览图：`preview/keepfresh-logic-flow.png`（已重存，1640 宽最终版）。
