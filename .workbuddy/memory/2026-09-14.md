## 修复「食谱 / 我的」打不开 + 拍照链路加固 + Tab 改名

### 1. 食谱页与我的页打不开（根因又是 barrel 模块）
- 现象：首页 / 我的冰箱正常，**食谱、我的 两个 Tab 白屏**（拍照页也受影响）
- 唯一共同点：这两个页面 `import ... from '../../services/ai'`（barrel）
- 真凶：`services/ai/index.ts` 末尾有 `export type { RecognitionResult, RecognizedItem, VisionProvider }`。
  小程序按单文件编译，把类型再导出可能被当作**运行时具名导出**，模块初始化即报错 → 引入方整页白屏
- 处理：
  1. **彻底移除 index.ts 里的类型转发**（之前只补了 import，没根治）
  2. **recipe.ts / profile.ts 改为直接依赖叶子模块**
     （`services/ai/config` 取配置、`services/ai/opencode-zen` 取 chat/testConnection），
     不再依赖 barrel —— 只有 scan 页还依赖 barrel
  3. `profile.onShow` 的 `getAiConfig()` 包 try/catch，取不到也不拖垮整页
- **规则沉淀：小程序里禁止在 barrel 文件里转发类型；业务页尽量直接 import 叶子模块。
  遇到「某几个页面同时白屏」，先按 import 依赖分组找共同依赖。**
