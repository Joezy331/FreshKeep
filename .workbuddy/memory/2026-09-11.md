## 修复「首页在开发者工具里加载不出来」

排查结论与处理（WXSS 已先验证无语法/分号错误，排除样式问题）：

1. **根因（高概率）：`services/ai/index.ts` 用了动态 `import()`**
   - 小程序 TS 编译对动态 import 支持不稳定，模块解析失败会让**引入 services/ai 的页面整页白屏**
   - 改为顶部静态 `import { OpenCodeZenProvider, chat, testConnection } from './opencode-zen'`，
     `aiChat()` 不再动态导入；`testConnection` 也改成直接导出函数（不用 re-export 动态链）
   - **规则：小程序里禁止用 `await import()`，一律静态 import**

2. **开屏页跳转单点依赖 `wx.switchTab`**：改为 `wx.reLaunch` 优先 → 失败回退 `switchTab` →
   仍失败则把 errMsg 显示在页面上；1.2s 后出现「直接进入」按钮，用户随时可手动进首页。

3. **兜底加固**：
   - `home.ts`：`currentProviderName()` 用 try/catch 包住，引擎名取不到也不影响首页渲染
   - `app.ts`：`ingredients` 不是数组时重新灌演示数据（用户主动清空得到的 `[]` 不会被覆盖）；
     注册 `wx.onPageNotFound` → reLaunch 到首页；`track()` 外层加 try/catch

## 修复「首页 / AI食谱 / 我的 三个 Tab 页全部白屏」（续）

4. **真正的根因：`services/ai/index.ts` 里 `export type { RecognitionResult, RecognizedItem, VisionProvider }`，
   但 `RecognizedItem` 没有在本文件 import**
   - 小程序 TS 按**单文件**编译，判断不出它是纯类型，会当运行时具名导出去 re-export 一个
     不存在的绑定 → 模块初始化 `ReferenceError` → **所有 import services/ai 的页面整页白屏**
   - 命中面正好是 home / recipe / profile（scan 也会中招），fridge 不 import 所以没中
   - 修复：补 `import type { RecognitionResult, RecognizedItem, VisionProvider } from './types'`
   - **规则：凡是 `export { X }` / `export type { X }`（不带 from），X 必须在本文件显式 import 或声明**
   - 新增自检：正则扫描「导出名是否有来源」，已纳入回归校验（EXPORT CHECK）

5. **`wx.onError` 现在会 Toast 显示错误摘要**（原来只 console.error，白屏时完全没有线索）
