## 2. 百度智能云菜品识别测试（未执行 + 人工流程）

### 2.1 为何未执行
- 识别调用链在 `pages/scan/scan.ts`（OAuth 换 token → `/rest/2.0/image-classify/v2/dish`），但**需要管理员在「我的」页配置的百度 API Key/Secret**。
- 本仓库不含任何真实密钥（安全红线）；历史硬编码密钥已移出，**须到百度智能云控制台轮换**。故无法自动调用。

### 2.2 测试集设计（建议 30–50 张，覆盖）
- 单一食材 / 多种食材同框 / 不同角度 / 不同光照 / 部分遮挡 / 蔬菜·肉类·水果 / 易混淆相似食材（如 西红柿↔番茄、白菜↔生菜）。

### 2.3 指标口径
- **接口调用成功率** = 成功获得有效接口响应的请求数 ÷ 总请求数 × 100%
- **识别正确率** = 正确识别样本数 ÷ 有效测试样本数 × 100%（有效样本 = 接口成功且返回可解析结果）

### 2.4 输出字段（CSV 列）
图片编号, 真实标签, 预测标签, 是否正确, 调用状态, 响应时间(ms), 错误原因, 状态

### 2.5 可操作的人工测试流程（拿到密钥后）
1. 微信开发者工具打开项目，长按「我的」页脚版本信息进入管理员模式。
2. 「百度智能云」填入 API Key / Secret Key（仅存本地，不下仓库）。
3. 准备测试图集，逐张在scan页拍照/选图，记录返回 `name` 与 `probability`。
4. 用 `recognition_test_results.csv` 模板逐行填写；低置信度(<0.5)按"需确认"计。
5. **严禁**把 Key/Secret/Token 写入本仓库、日志或任何文档。

### 2.6 当前状态
`recognition_test_results.csv` 仅含 1 行占位，状态="未执行"。**不得**将其当作已通过。
