# 百度菜品识别 · 真实调用测试操作清单（Recognition Test Runbook）

> 用途：在**微信开发者工具 / 真机**里配置有效百度 Key 后，实跑菜品识别并把结果回填 `recognition_test_results.csv`。
> 说明：本清单所测的是**真实百度智能云 `/rest/2.0/image-classify/v2/dish` 调用**，不是 Mock；本环境（Node）无法发起 `wx.request`，故只能由你在小程序内执行。

---

## 0. 前置条件

1. **已轮换并拿到新 Key**：百度智能云控制台「安全认证」删除旧 Key、新建一对 `API Key` + `Secret Key`。
2. **录入 Key 到小程序**：打开小程序「我的」页 → **长按页脚版本信息**进入管理员模式 → 填 `API Key` / `Secret Key`（仅存本地 `fk:baidu_creds`，不下仓库）。
3. **准备测试图集（30–50 张）**：覆盖单一食材 / 多食材同框 / 不同角度 / 不同光照 / 部分遮挡 / 蔬菜·肉类·水果 / 易混淆项（西红柿↔番茄、白菜↔生菜）。每张图记录"真实标签（人工标注）"。
4. ⚠️ **红线**：Key 绝不写进仓库、代码、文档或聊天；生产环境应改后端代理转发。

## 1. 小程序内识别链路（代码事实，便于定位）

`pages/scan/scan.ts` 真实调用流程：
1. `getBaiduCreds()` 读本地 Key；无 Key → `wx.showToast('请先配置百度智能云密钥')` 并中止。
2. 图片转 base64，超 `MAX_BASE64_LEN` 守卫 → 提示图片过大。
3. `wx.request` 换取 `access_token`（OAuth `client_credentials`）。
4. `wx.request` POST 到 `/rest/2.0/image-classify/v2/dish?access_token=...`，body `image=base64`。
5. 取 `result[0]` 为 Top-1：`name` + `probability`；低置信度（`<0.5`）提示"结果可能存在误差，请确认"。
6. `toRecognizedItem(name, probability)` 把百度名映射到食材知识库（名称/emoji/分类/保存方式/分区/天数）。

> 当前代码**只取 Top-1**（多食材同框缺陷 D5 未处理）。因此"识别正确率"按**每张图 Top-1** 计。

---

## 2. 执行步骤（每张图）

1. 微信开发者工具导入项目，编译预览到手机或模拟器。
2. 进入首页 → 「拍食材入库」/「我的冰箱」→ 底部「+」→ 拍照或相册选图。
3. 观察返回：成功 → 显示识别名称 + 置信度；失败/超时/无结果 → 对应提示。
4. 对照你的人工标注"真实标签"，判定 `是否正确`：
   - Top-1 与真实标签（或合理别名，如 番茄=西红柿）一致 → 正确；
   - 否则 → 不正确；
   - 接口报错/无返回 → 调用失败（记 `调用状态=失败` + `错误原因`）。
5. 把一行填入 `recognition_test_results.csv`（见 §3）。
6. 重复至 30–50 张。

## 3. CSV 回填格式

现有 `recognition_test_results.csv` 列：`图片编号, 真实标签, 预测标签, 是否正确, 调用状态, 响应时间(ms), 错误原因, 状态, 测试类型`

| 列 | 填法 |
|----|------|
| 图片编号 | 如 `IMG_01` |
| 真实标签 | 人工标注的食材名 |
| 预测标签 | 小程序返回的名称（含 Top-1；若有 our 归一名可附 `原始=百度名`） |
| 是否正确 | `是` / `否` |
| 调用状态 | `成功` / `失败` / `无结果` |
| 响应时间(ms) | 开发者工具 Network 面板看请求耗时，或凭体验估算（标注"估"） |
| 错误原因 | 失败时的提示文案 |
| 状态 | 整批完成后填 `已执行` |
| 测试类型 | `real-api` |

> 删除首行的"未执行"占位行，整批填完后再把首行状态改为 `已执行`。

---

## 4. 指标口径（回填后计算）

- **接口调用成功率** = 成功获得有效响应的请求数 ÷ 总请求数 × 100%
- **识别正确率（Top-1）** = 正确识别样本数 ÷ 有效测试样本数 × 100%（有效样本 = 接口成功且返回可解析结果）
- 低置信度（<0.5）样本按"需确认"计，不计入"正确"也不计入"错误"，单独列示。
