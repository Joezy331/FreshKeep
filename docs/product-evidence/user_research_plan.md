# 用户研究方案与记录模板（User Research Plan）

> 日期：2026-10-19
> 状态：**未执行**（当前无法招募真实用户）。本文仅提供可执行方案与记录模板，**不伪造任何访谈结果**。
> 区分：真实用户反馈 / 个人自测 / 模拟反馈——三者严格分开。

---

## 1. 研究目标
验证核心闭环（拍照录入 → 查保存建议 → 看临期 → 按库存找菜谱 → 消耗更新）在真实用户手上的**完成率、耗时、障碍与价值感知**，为迭代优先级提供证据。

## 2. 招募计划
- 样本：5–8 名目标用户（家庭做饭人群，含 1–2 名低频做饭者作对照）。
- 渠道：朋友圈/社群招募，小红书/微信社群发布招募帖。
- 激励：小额礼品卡（建议 20–30 元/人）。
- 伦理：知情同意，数据仅用于产品改进，不外泄。

## 3. 测试任务（逐条观察）
1. 拍照录入一份刚买回来的食材（验证录入成本与识别兜底）。
2. 找到其中某食材的保存建议（验证建议可达性）。
3. 查看冰箱中即将临期的食材（验证临期提醒可读性）。
4. 根据库存找到一道合适的菜谱（验证推荐相关性）。
5. 完成食材消耗与库存更新（验证闭环收尾）。

## 4. 记录模板（每人一行）

| 用户ID | 任务1完成 | 任务1耗时(s) | 任务1错误 | 求助次数 | 任务2完成 | … | 主观满意度(1-5) | 最有价值功能 | 最大障碍 | 改进建议 |
|--------|---------|------------|---------|---------|---------|---|------------|-----------|---------|---------|
| U01 | Y/N | | | | Y/N | … | | | | |
| U02 | | | | | | | | | | |

> 量化指标：任务完成率 = 完成任务数 ÷ 总任务数；耗时分布取中位数；问题严重度（阻断/主要/次要）由主持人判定。

## 5. 输出要求
- 任务完成率、耗时分布、问题严重度与优先级。
- **真实用户反馈**单独成段；**个人自测**（开发者自己走查）单独成段；**模拟反馈**明确标注、不混入真实结论。
